# 라이선스 요약 항목 도움말 설계

## 목표

라이선스 요약의 각 항목이 무엇을 뜻하는지 초보 사용자도 바로 이해하게 한다.

## 원인

현재 `LicenseSummaryCard`의 항목은 `label`, `value`, `state`만 가진 일반 텍스트다. 설명 데이터와 도움말을 여는 요소가 없어서 마우스, 키보드, 모바일 모두 안내를 표시할 수 없다.

## 적대적 검토

- **법적 단정 위험:** 도움말은 특정 폰트의 허용 여부를 판단하지 않는다. 항목의 뜻만 설명하고 실제 판단은 옆의 `허용`, `조건부`, `금지`, `확인 필요` 값과 공식 원문에 맡긴다.
- **상업적 사용과 판매 혼동:** “폰트를 사용한 결과물”과 “폰트 파일 자체 판매”를 분리한다.
- **재배포 범위 혼동:** 결과물 공유가 아니라 폰트 파일 자체를 다시 제공하는 행위라고 명시한다.
- **임베딩과 웹폰트 혼동:** 임베딩은 문서·전자책·앱 안에 폰트 파일을 포함하는 행위로, 웹폰트는 웹사이트가 폰트 파일을 불러와 표시하는 행위로 설명한다.
- **출처 표기 과잉 단정:** 사용·배포 상황에 따라 조건이 달라질 수 있으므로, 무엇을 확인하는 항목인지만 설명한다.
- **마우스 전용 접근성 실패:** hover만 지원하지 않는다. 키보드 focus와 모바일 tap에서도 같은 설명을 표시한다.

## 확정 문구

| 항목 | 설명 |
| --- | --- |
| 상업적 사용 | 광고·상품·웹사이트·영상 등 상업 활동의 결과물에 폰트를 사용할 수 있는지 뜻해요. |
| 수정 | 글자 모양이나 폰트 파일을 바꿔 파생 폰트를 만들 수 있는지 뜻해요. |
| 재배포 | 폰트 파일 자체를 다른 사람에게 다시 제공할 수 있는지 뜻해요. |
| 임베딩 | 폰트 파일을 PDF·전자책·앱 같은 문서나 프로그램 안에 포함할 수 있는지 뜻해요. |
| 폰트 판매 | 폰트 파일 자체를 단독 상품으로 판매할 수 있는지 뜻해요. 폰트를 사용한 결과물 판매와는 달라요. |
| 출처 표기 | 폰트 사용이나 파일 배포 시 제작자·라이선스 정보를 밝혀야 하는지 확인하는 항목이에요. |
| 웹폰트 | 웹사이트에서 폰트 파일을 불러와 화면 글꼴로 사용할 수 있는지 뜻해요. |

## UI 설계

- 항목 이름 옆에 작은 정보 버튼을 둔다.
- 항목 이름 또는 버튼에 마우스를 올리면 도움말을 표시한다.
- 정보 버튼에 키보드 초점이 가거나 모바일에서 누르면 도움말을 표시한다.
- 버튼은 `<button type="button">`을 사용하고 `aria-label`과 `aria-describedby`로 설명을 연결한다.
- 도움말은 `role="tooltip"`을 사용한다.
- 새 라이브러리나 클라이언트 상태는 추가하지 않고 CSS의 hover/focus로 처리한다.

## 검증

- 컴포넌트 테스트로 도움말 버튼의 접근 가능한 이름과 설명 연결을 확인한다.
- 실제 브라우저에서 마우스 hover, 키보드 focus, 모바일 크기 tap을 확인한다.
- 웹 전체 테스트, 린트, 프로덕션 빌드를 실행한다.
