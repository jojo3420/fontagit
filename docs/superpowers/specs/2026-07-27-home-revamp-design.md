# 홈화면 개편 설계 (이슈 #128)

- 날짜: 2026-07-27
- 상태: 사용자 승인 완료
- 관련: [이슈 #128](https://github.com/jojo3420/fontagit/issues/128)
- 목업: `docs/mockups/2026-07-27-home-revamp/layout-options.html` (레이아웃 A/B/C 비교, A 채택)

## 목표

홈(`/`)의 세 가지 문제를 해결한다: (1) 분류 칩이 장식일 뿐 동작하지 않음, (2) 중앙이 비어 보이고 우측 TOP 10만 세로로 김, (3) 정보 밀도 부족. 동시에 `/collections` 목록 페이지를 홈으로 통합한다.

## 확정 결정 로그

| 항목 | 결정 |
|---|---|
| 분류 칩 | 홈 내 즉시 필터링 (페이지 이동 없음) |
| 데이터 범위 | 미리보기 그리드 — 분류별 대표 8종만 빌드 시 탑재, 전체는 /fonts 링크 |
| TOP 10 패널 | 그대로 유지. 삭제-수정 금지 |
| 필터 데이터 기준 | 분류 데이터(category_ko) 재정비 선행 (태그 근거 교정) |
| 가격 칩 | 무료/유료 유지 (유료 0종은 빈 상태 처리) |
| 컬렉션 | 신규 4개 추가로 10 → 14개 |
| 추가 채택 | 페어링 프리셋 + 카드 통계 뱃지 (경쟁 분석 제안 3-4번) |
| 레이아웃 | A안 "탐색 우선" |

## AS-IS

홈은 좌측 Hero(제목 + 동작 없는 칩 6개: 한글/고딕/명조/손글씨/무료/유료)와 우측 WeeklyRankPanel(TOP 10) 2컬럼, 아래 비교 보드(CompareLazy)와 광고로 구성된다. `/collections`는 별도 페이지로 published 컬렉션 10개를 보여준다. prod 데이터는 분류가 고딕 1,199 / 명조 19 / 장식 14 / 손글씨 8로 치우쳐 있고(태그에는 캘리그라피 67, 붓글씨 72 등 풍부), 유료 폰트는 0종이다.

## TO-BE: 홈 구조 (레이아웃 A)

위에서부터:

1. **Hero + 즉시 필터 그리드** (좌) / **TOP 10 패널** (우, 무변경)
2. **추천 컬렉션 14개** — 가로 스크롤 스트립, Header "컬렉션" 메뉴는 이 섹션 앵커로
3. **페어링 프리셋** — 제목+본문 추천 조합 3세트
4. **비교 보드** — 기존 그대로
5. **광고** — 기존 그대로

## 상세 설계

### 1. 즉시 필터 영역 (신규)

- 칩: 분류 5개(전체/고딕/명조/손글씨/장식) + 가격 2개(무료/유료). 기존 "한글" 칩은 "전체"로 대체 (목업 승인 기준).
- 동작: 칩 클릭 → 미리보기 그리드 즉시 교체 (클라이언트 상태, 페이지 이동-URL 변경 없음).
- 데이터: 분류별 대표 폰트 8종을 빌드 시점(SSG) 선별. 선정 기준은 주간 클릭 인기순, 부족분은 최신 등록순.
- 그리드 마지막 칸: 해당 필터를 쿼리로 건 `/fonts` "전체 보기" 링크 (기존 `buildFilterQuery` 재사용).
- 유료 칩: 대상 0종이므로 기존 EmptyState 컴포넌트로 "준비 중" 안내.

### 2. 분류 데이터 재정비 (선행, 파이프라인)

- 태그 → 분류 매핑 규칙(초안): 캘리그라피-붓글씨-어른 손글씨-삐뚤빼뚤 → 손글씨 / 바탕체-고전체 → 명조 / 장식체-픽셀-레트로 → 장식 / 그 외 고딕 유지.
- 충돌 시 우선순위: 손글씨 > 장식 > 명조 > 고딕.
- 적용 순서: dev DB 적용 → 분포 검증 → prod 반영. metadata 자동화 대상(2026-07-23 결정)이라 자동 게이트로 진행하되, prod 쓰기 직전 사용자 확인 1회.
- 매핑 규칙은 파이프라인 단위 테스트로 검증.

### 3. 컬렉션 통합

- `/collections` 목록 페이지 삭제. 정적 사이트(output: export)이므로 Cloudflare Pages `_redirects`로 `/collections/ → /` 처리. sitemap에서 목록 URL 제거.
- 상세 `/collections/{slug}`는 유지 (카드 진입점).
- 신규 4개: 귀여운-둥근 / 레트로-고전 / 캘리그라피-붓글씨 / 제목용 임팩트. 태그 기반으로 각 10~15종 후보 추출 → 사용자 확인 → 시드 스크립트로 dev/prod 반영.
- 홈 컬렉션 스트립은 published 14개를 sort_order 순으로 노출.

### 4. 페어링 프리셋 + 통계 뱃지

- 페어링: 3세트를 데이터 파일(하드코딩 금지, 상수 모듈)로 정의. 클릭 시 기존 비교 보드에 해당 폰트 조합 로드.
- 뱃지: 홈 미리보기 카드에 "인기"(주간 클릭 상위), "NEW"(최근 등록) 2종만.

### 5. 에러 처리-테스트

- 필터 결과 0건 → EmptyState. SSG라 런타임 로딩 상태 없음.
- 컴포넌트 테스트(vitest): 칩 전환, 빈 상태, 뱃지 노출, 페어링 로드. db import 컴포넌트는 db 모듈 mock 필수.
- 배포 후 prod에서 `/collections` 리다이렉트 실측 확인.

## 범위 제외 (YAGNI)

- 홈 내 전체 목록 탐색(전체 1,000+종 탑재), 폰트 스토리/Brand Voice 섹션, 검색창 신설, TOP 10 패널 변경.

## 리스크

- 분류 재정비 결과가 기대 분포와 다를 수 있음 → dev 검증 게이트로 완화.
- 홈 첫 화면 페이로드 증가(대표 폰트 웹폰트 로딩) → 미리보기 8종 한정 + 지연 로딩으로 완화.
- 유료 칩은 당분간 빈 상태만 노출됨 (사용자 결정으로 유지).

## 참고: 경쟁 분석 요약

눈누-산돌구름-Google Fonts-Fontshare-Adobe Fonts-DaFont 조사 결과, 공통 패턴은 홈 즉시 필터, 큐레이션 노출, 최신+인기 이원 노출, 통계 신호 활용. 본 설계는 제안 1(즉시 필터)-2(큐레이션)-3(페어링)-4(뱃지)를 반영하고 5(스토리 섹션)는 제외했다.
