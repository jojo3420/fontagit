## 3. 통합 권고 (합집합)

### 즉시 반영 (Must) - 구현 착수 전 설계 문서에 반영

1. **폰트 식별자 단일화** (Codex #3). 캔버스 객체-계측-CTA-스냅샷이 모두 같은 키(`slug` 권장)를 쓰도록 못 박고, 표시명-CSS 패밀리-스타일시트 URL은 그 키로 조회하는 구조로 정의한다.
2. **Tier B 진입 정책** (Codex #2). 폰트 상세의 "이 폰트로 만들어보기"는 웹 렌더링 가능한 폰트에서만 노출한다. Tier B에서는 버튼을 숨긴다.
3. **단축키 컨텍스트 분리** (agy #11). 인라인 텍스트 편집 중이거나 입력 요소에 포커스가 있으면 전역 단축키를 무시한다.
4. **undo/redo 복원 잠금** (agy #12). 복원이 끝나기 전 다음 복원을 시작하지 않는다.
5. **폰트 로딩 완료 시 대상 유효성 검사** (합의 #5). 반영 직전 대상 객체가 여전히 캔버스에 있는지 확인하고, 없으면 조용히 버린다.
6. **스냅샷에 폰트 식별자 보존** (Codex #6). 직렬화 대상 커스텀 속성을 명시한다.
7. **내보내기 직전 폰트 로딩 확인** (Codex #10). 사용 중 폰트가 모두 준비된 뒤 PNG를 만든다.
8. **weight 대체 규칙** (Codex #4). 프리셋 기본 weight가 없으면 가장 가까운 값으로 대체한다.
9. **모바일 동작 명세 + 터치 처리** (Codex #7, agy #13). 모바일에서 되는 것(텍스트 추가, 내용 편집, 폰트 적용, 이동, 내보내기)과 안 되는 것(크기 조절, 회전)을 문장으로 확정하고, 캔버스 터치가 페이지 스크롤로 새지 않게 처리한다.
