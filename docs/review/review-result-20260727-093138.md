## 2. Claude 크로스 리뷰

### 종합 소견
환각 없이 실제 코드 구조와 부합하는 고품질 리뷰다. 특히 2(서버/클라 경계), 4(견본 행의 SSoT를 variants 조합으로), 5(합성 방지)는 그대로 구현했다면 "가짜 굵기 금지"라는 이슈 핵심 요구를 위반할 수 있었던 실결함 지적이다.

### 동의하는 핵심 피드백 Top 3
1. **#4 견본 행 SSoT = variants 조합**: confirmedWeights만으로 행을 만들면 이탤릭 전용 굵기에서 합성 견본이 노출된다 — 이슈 요구 직접 위반 방지.
2. **#2 클라이언트 래퍼**: SSG(output: export) 구조 보존의 필수 조건. 빌드 깨짐(서버 searchParams 함정과 동류)을 사전 차단.
3. **#5 font-synthesis: none**: "브라우저가 흉내 낸 가짜 굵기 금지"를 실제로 보장하는 유일한 CSS 수단.

### 동의하지 않는 피드백
- 전면 부정할 항목 없음. #6만 축소 채택(글리프 전수 검사 대신 정적 안내 — GlyphChecker가 이미 별도 존재).

### Codex가 놓친 추가 관점
- 이탤릭 배지 "미지원" 판정에 confirmedWeights가 아닌 variants 보유가 전제라는 점은 스펙 3장에 이미 있었으나, Tier A인데 variants가 비어 있는 예외(구 데이터)의 판정(→ unknown)을 스펙에 명시할 필요.
