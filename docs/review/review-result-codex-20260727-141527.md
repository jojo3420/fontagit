### 종합 평가
- 전체 점수: 8/10
- 한줄 요약: 큰 방향은 좋지만, legal 판정 기준과 적용 전 검증 기준이 더 구체화되어야 안전합니다.

### 구체적 피드백

1. [Blocker] KOGL 권한 매핑은 공식 문구 대조 전까지 확정값처럼 쓰면 안 됩니다.  
   표 자체는 초안이라고 되어 있지만, 적용 설계 안에서는 거의 확정처럼 보입니다. “공식 기준 확인 전에는 권한값 생성 금지”를 명시해야 합니다.

2. [Blocker] prod 적용 전 rollback 기준이 없습니다.  
   manifest 적용 후 잘못된 권한값이나 제작사명이 들어가면 되돌릴 방법이 필요합니다. 최소한 `before` 값 기반 복구 manifest 생성 여부가 필요합니다.

3. 제작사 정의가 모호합니다.  
   “제작사 = 권리사”라고 했는데, S4에서는 “제작사=네이버 계열”이라고 합니다. 예를 들어 Sandoll, NHN, Naver 중 무엇을 보여줄지 기준이 더 필요합니다.

4. download_url 정의가 UX와 충돌할 수 있습니다.  
   Google Fonts `files["regular"]`는 실제 폰트 파일 URL입니다. 사용자가 기대하는 “다운로드 페이지”인지 “폰트 파일 직접 링크”인지 명확히 나눠야 합니다.

5. 자동 게이트 기준이 부족합니다.  
   “공식 도메인 화이트리스트”가 있다고 하지만 어떤 도메인이 통과인지, 불일치 시 어떤 필드만 needs_review인지가 빠져 있습니다.

6. 재크롤 22종 기준이 더 필요합니다.  
   “실패 지속 건만 재크롤”은 좋지만, 실패 재현 기준이 없습니다. HTTP 실패, 파싱 실패, 데이터 누락, 차단 응답을 구분해야 합니다.

7. manifest 청크 무결성은 좋지만 적용 결과 검증 기준이 약합니다.  
   적용 전 무결성뿐 아니라 적용 후 DB에서 “기대 변경 수 = 실제 변경 수”를 검증해야 합니다.

8. 사람 게이트 승인 기록 방식이 없습니다.  
   KOGL 유형별 일괄 승인 시 누가, 언제, 어떤 기준으로 승인했는지 남겨야 나중에 추적 가능합니다.

9. 견본 문구 풀은 범위가 다소 섞여 있습니다.  
   라이선스/크롤 고도화 문서 안에 웹 UX 개선이 들어와 있습니다. 작게 끝낼 수 있지만, 데이터 감사 작업과 배포 리스크가 다릅니다.

10. 테스트 범위는 적절하지만 핵심 우선순위가 필요합니다.  
   가장 중요한 테스트는 KOGL 파서, 권한 매핑, manifest 무결성입니다. 견본 문구 테스트는 낮은 우선순위입니다.

### 개선 제안

1. 최우선: KOGL 적용 전 “공식 기준 확인 체크포인트”를 S3에 추가하세요.  
   확인 전에는 `allow_commercial`, `allow_modify` 값을 생성하지 않고 preview만 생성하는 구조가 안전합니다.

2. 최우선: prod 적용용 rollback manifest를 필수 산출물로 넣으세요.  
   적용 manifest마다 되돌리기 manifest가 있어야 합니다.

3. 높음: 용어를 4개로 분리하세요.  
   `rights_holder`, `designer`, `source_label`, `source_url`처럼 권리사·디자이너·출처표기·원문 URL을 분리하면 혼선이 줄어듭니다.

4. 높음: download_url의 의미를 명확히 하세요.  
   직접 파일이면 `download_file_url`, 소개/배포 페이지면 `download_page_url`처럼 나누는 편이 낫습니다.

5. 중간: dry-run 산출물 기준을 추가하세요.  
   예: 변경 대상 수, needs_review 수, KOGL 유형별 수, download_url 백필 수, 제작사 자동승인/불일치 수.

6. 중간: 사람 승인 단위를 문서화하세요.  
   “제1유형 123건 승인”처럼 그룹 승인하되, 샘플과 공식 기준 링크를 함께 남기는 방식이 좋습니다.

7. 낮음: 견본 문구 다양화는 별도 작은 슬라이스로 분리하는 편이 더 깔끔합니다.  
   지금 문서에 남겨도 되지만, 데이터 감사 실패와 웹 UX 변경 실패를 분리해 배포 판단하기 쉬워집니다.
