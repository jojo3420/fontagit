## 다음 기능 — 이슈 #107

- 이슈: https://github.com/jojo3420/fontagit/issues/107
- 제목: 폰트 상세 화면에 굵기별 견본과 이탤릭 지원 정보 추가
- 목적: 확인된 굵기·이탤릭만 정확히 표시하고, 빈 굵기를 `Regular 400`으로 추정하는 오류를 없앤다.
- 예상 규모: 7~10개 파일, 개발 1.5~3일.
- Tier B 1,110종 데이터 전수 보강과 폰트 파일/CDN 확보는 #107 범위 밖이다.
- #107 전용 Design/Plan 문서는 아직 없다. 이슈 본문을 명세로 삼아 먼저 작성해야 한다.

### #107 구현에서 지켜야 할 경계

- Tier A는 Google Fonts에서 실제 확인된 굵기·이탤릭만 상세 화면에 로드한다.
- Tier B/C에는 새 외부 요청을 추가하지 않는다.
- 실제 폰트 파일이 없으면 브라우저 합성 굵기를 실제 굵기처럼 표시하지 않는다.
- 목록 화면의 기존 지연 로딩과 400/700 대표 굵기 로딩 성능을 악화시키지 않는다.
- 실제 로드 여부는 `document.fonts`로 확인한다.
